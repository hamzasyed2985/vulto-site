# Vulto Planner — Marketing Site

High-converting marketing website for [Vulto Planner](https://vulto.co), a mindful daily planning and timeboxing tool.

## Stack

- **Next.js** (App Router)
- **Tailwind CSS** v4
- **GSAP** + **Framer Motion**
- **Lucide React** + **Radix UI**

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm start` — serve production build
- `npm run lint` — ESLint
